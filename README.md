# 照片墙 Photo Wall

一个现代化的网页照片墙应用，支持照片上传、展示、管理和排序。

## 功能特性

### 🖼️ 照片管理
- **多文件上传**：支持同时选择多张照片
- **拖拽上传**：直接拖拽照片到上传区域
- **缩略图生成**：自动生成高质量缩略图
- **本地存储**：照片数据保存在浏览器本地存储中

### 🎨 用户界面
- **响应式设计**：完美适配桌面和移动设备
- **现代化UI**：采用渐变背景和毛玻璃效果
- **流畅动画**：照片加载和交互都有流畅的动画效果
- **直观操作**：简单易用的用户界面

### 🔧 交互功能
- **照片预览**：点击照片查看大图
- **拖拽排序**：通过拖拽重新排列照片
- **删除照片**：支持单张删除和批量清空
- **下载照片**：从预览模式下载原始照片
- **键盘导航**：支持方向键浏览照片

### 📱 移动端优化
- **触摸友好**：针对移动设备优化的交互
- **自适应布局**：根据屏幕尺寸自动调整网格
- **手势支持**：支持触摸拖拽和滑动

## 技术栈

- **HTML5**：语义化标签和现代HTML特性
- **CSS3**：Flexbox、Grid、动画和响应式设计
- **JavaScript ES6+**：类、箭头函数、模块化编程
- **LocalStorage**：客户端数据持久化
- **Canvas API**：图片处理和缩略图生成

## 使用说明

### 上传照片
- **方式一**：点击"上传照片"按钮，选择多张照片
- **方式二**：直接拖拽照片文件到上传区域
- **支持格式**：JPG、PNG、GIF、WebP等常见图片格式

### 管理照片
- **查看大图**：点击任意照片进入预览模式
- **删除照片**：在预览模式下点击删除按钮，或点击照片上的垃圾桶图标
- **下载照片**：在预览模式下点击下载按钮
- **排序照片**：直接拖拽照片到新位置

### 键盘快捷键
- `←` `→`：在预览模式下切换照片
- `Esc`：关闭预览模式

## 存储限制

- 使用浏览器LocalStorage存储照片数据
- 一般浏览器限制为5-10MB
- 应用会自动压缩图片以节省空间
- 建议单张照片不超过2MB
